
=============================================
  Chemical Analysis - ChemBase Pro
=============================================

SETUP (one time only):
  1. Double-click  install.bat
     - It will automatically download & install Python and Node.js if missing.
     - It will install all required packages for both backend and frontend.
     - Just wait for it to finish. No manual steps needed.

RUN THE APP:
  2. Double-click  start.bat
     - It will start both the backend API and the frontend UI.
     - Open your browser to  http://localhost:5173

STOP THE APP:
  3. Press any key in the start.bat window.

REQUIREMENTS:
  - Windows 10 or 11 (64-bit)
  - Internet connection (for first-time install only)
