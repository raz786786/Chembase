# Workspace Superpowers Engineering Protocol

This workspace uses the **Superpowers** development methodology.

- **Before new features**: Invoke `brainstorming`.
- **Before coding plans**: Invoke `writing-plans`.
- **During coding**: Adhere to `test-driven-development` (RED-GREEN-REFACTOR).
- **When fixing bugs**: Invoke `systematic-debugging`.
- **Before marking completion**: Invoke `verification-before-completion`.
